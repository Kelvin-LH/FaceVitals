# 0.6.0 验证记录 — 2026-10-17

本版为研究预览版。目标验收仍为 partial：普通摄像头持续心率可用性和真人表情准确度尚未达标。用户选择按已有实测发布，并注明限制。

## 已完成

- Windows 实机真实摄像头采集；每次 70 秒，约 2084–2085 帧；不录制视频，不保存人脸图像。
- 修复固定 ROI/逐帧平滑后的实机运行出现 8 次有效心率分析输出，总计 69 次分析：20 次积累、41 次质量拒绝、8 次有效。20 秒后仍有大量拒绝，不能称为问题已完全解决。最终结束状态仍为 low_quality。期间没有连续性硬中断。
- 本轮心率没有同步接触式参考值，不能判断读数是否准确。上面运行发生在加入最终带通滤波之前。加入滤波后的实机运行，大部分时间未检测到人脸，因此没有验证稳定有效输出；不把该次运行当作通过。
- 表情修正后运行：343 次预测，329 次 uncertain、14 次 valid。没有独立标注真实表情，不能把 valid 数量、分数或拒绝率当作识别准确率。
- 人脸框裁切、坐姿和采集环境在不同实测间改变，不能据此做算法因果提升声明。公开硬件汇总见 hardware-summary.json；个人心率值、几何信息和逐帧数据未公开。
- 数值模拟：200 组带缺帧/到帧扰动的脉搏案例全部输出，冻结旧分析器为 100/200。400 组无脉搏噪声当前 0 次输出，旧分析器 1 次。只验证模拟条件。
- 表情回归：一张 NASA 公有领域图片的 18 个比例/平移/亮度变体与 4 个倾斜变体通过；含严重曝光、裁切和无效输出边界检查。单图变体不是独立受试者。
- 当前候选模型升级未通过既定图片回归门槛，未采用。

## 公开数据回放的限制

本地下载 MPU 研究样例，不随仓库分发。帧数与 CSV 行数相同，但文件配对及同步偏移未独立确认，alignment_status=unconfirmed。前 120 秒回放中的运动/光照中断使当前与冻结旧分析器均没有有效输出；没有可报告的 MAE 或准确度提升。开发工具 tests/ReplayCheck.cpp 与 scripts/replay-video-frames.py 可复查流程；参考来自原始 CSV，未从模型生成，未搜索最佳偏移。

## 尚未完成的验收

1. 最终版本在完整人脸、均匀照明下重复实测，并记录暖机后输出覆盖率与拒绝原因。
2. 与同步、经过验证的脉搏设备比较心率误差；对不同人群、肤色、运动和光照测试。
3. 建立独立标注的多人表情测试集，报告每类准确度、混淆矩阵与拒绝率；不得把表情推断当作内心情绪诊断。
4. 普通 RGB 摄像头下血压和血氧没有经过校准验证的测量链路，保持 unsupported。不能用心率、肤色或正常值模板代填。

Windows CTest：5/5 测试组通过，见 windows-ctest.txt。发布包在移除开发环境 PATH 后启动和模型初始化成功；ZIP 解压后逐文件哈希全部匹配，解压版启动通过，见 delivery-check.json。Linux 0.6 尚未复测，本次只发布 Windows 二进制与跨平台源码。
